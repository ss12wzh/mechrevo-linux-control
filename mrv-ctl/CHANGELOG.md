# 变更记录

## 3.4.3 — 2026-09-25 · 多机型适配

- 新增机型适配层 `mrvmodel.py` + `data/models.json`：识别 DMI / BIOS / EC 平台代际 / CPU / GPU PCI ID，匹配已验证机型档案；按 DSDT 方法与 EC 可读性决定各功能是否开放，并给出原因
- 新增 `mrvctl calibrate`（GUI：设置 → 校准功耗墙）：本机实测各档 CPU 功耗墙，按主板 + BIOS + CPU 存盘，BIOS 升级自动失效；优先级 本机校准 > 内置档案 > 无
- 新增 `mrvctl info`
- 静音档联动关闭 CPU 睿频；GUI 显示"睿频已关"；最高频率改读 `amd_pstate_max_freq`
- 开机恢复档位不再覆盖用户手动调过的键盘灯亮度
- GUI 刷新标志超时自愈；`MRV_GUI_DEBUG=1` 调试日志；`scripts/gui-debug.py`、`scripts/idle-probe.py`

## 3.3.2 — 2026-09-25

- 修复窗口边缘一圈暗色直边（阴影超出透明边距被截断）
- 修复滑条拉到两端时滑块只显示一半

## 3.3.1 — 2026-09-25 · 性能档复核

- 满载实测三档全部生效：CPU 45 / 87 / 130 W，GPU 上限 105 / 85 / 115 W；旧"切档无差异"结论作废
- `status` 新增平台参数（EC TPP / 动态加速 / cTGP 基础值 / 各档 CPU 功耗墙），`mrvctl status` 与 GUI 同步显示
- 新增性能测量工具 `scripts/perf-*.{py,sh}` 与 `docs/perf/` 数据

## 3.3.0 — 2026-09-25 · 风扇

- 新增风扇强冷（EC 全速模式）与高温自动强冷（默认 ≥88°C 开、≤78°C 关）
- EC 写入改走 WKBC 命令通道；不再清除 0x0741 bit0；删除写只读 PWM、从未生效的曲线引擎
- 切档与强冷共用一把锁读改写 0x0751
- 新增受控风扇实验脚本 `scripts/fan-experiment.py` 与 7 份实验日志

## 3.2.0 — 2026-09-25 · 界面重做

- 按 token-monitor 的设计语言重做：无边框石墨面板、细线分区、胶囊分段标签、大号数字、6px 进度条
- 概览 / 控制两个视图；显卡模式内联二次确认；键盘灯预设色块
- 悬浮窗改为圆角胶囊；窗口位置与视图等设置保存在 `~/.config/mrv-ctl/gui.json`

## 3.1.1 — 2026-09-25 · 止血

- 修复：灯效下拉不生效；`/proc/acpi/call` 并发无锁；风扇曲线写只读 PWM 却报告成功；切档联动执行两遍；状态文件并发丢更新
- 安全：IPC 按调用方 uid 鉴权；sysfs 开关白名单；GUI 以普通用户运行、不再截屏写 `/tmp`
- 性能：IPC 每连接一个线程；独显休眠时不调用 `nvidia-smi`
- 打包：`install.sh` 统一为构建并安装 deb；清理旧安装残留
